## API surface

Everstream Analytics sells API access but publishes no public developer portal, no
OpenAPI/Swagger/GraphQL/AsyncAPI contract, no SDK and no sandbox. Reference documentation
lives behind customer authentication. Two API products are named on the public site:

- Reveal API — real-time incident risk for monitored entities (suppliers, facilities)
  and for locations, lanes and shipments.
- Explore API — supply chain data for long-term planning decisions.

Delivery transports described publicly: API connectivity (bidirectional, real-time),
webhooks (event-driven notifications), and SFTP (scheduled batch file transfer).

Observed integration host: https://int.us1.apps.everstream.ai (AWS API Gateway; the EU
region equivalent is int.eu1.apps.everstream.ai). No unauthenticated route is exposed.

## Disambiguation

Everstream Analytics (everstream.ai, supply chain risk analytics) is a different company
from Everstream Solutions LLC (everstream.net, a US fiber network operator). Compliance
claims, status pages and certifications published under everstream.net do not belong to
Everstream Analytics.
